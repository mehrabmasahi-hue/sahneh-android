🔐 قفل محلی برنامه

این PIN فقط روی همین مرورگر اعمال می‌شود و جایگزین حساب کاربری امن یا سرور نیست.

☁️ انتقال و همگام‌سازی اطلاعات

برای جابه‌جایی اطلاعات بین دستگاه‌ها از فایل پشتیبان استفاده کن: روی دستگاه اول «دانلود پشتیبان» و روی دستگاه دوم «بازیابی پشتیبان» را بزن. همگام‌سازی ابری خودکار به سرور و حساب کاربری نیاز دارد و در این فایل مستقل فعال نیست.

☁️ اتصال Google Drive

پشتیبان صحنه در پوشهٔ قابل‌مشاهدهٔ «صحنه» ذخیره می‌شود. اتصال از OAuth گوگل و مجوز محدود drive.file استفاده می‌کند؛ رمز عبور گوگل در برنامه ذخیره نمی‌شود.

Client ID را از Google Cloud Console بساز و Authorized JavaScript origins را برای آدرس HTTPS سایت یا localhost تنظیم کن. فایل محلی file:// معمولاً برای OAuth قابل استفاده نیست.

برای شروع، Client ID را وارد و ذخیره کن.

🔔 یادآوری‌ها

برای دیدن اعلان‌ها، اجازهٔ مرورگر را فعال کن. اعلان‌ها هنگام باز بودن برنامه بررسی می‌شوند؛ اعلان تضمینی در زمان بسته بودن فایل محلی نیست.

📲 نصب و کارکرد آفلاین

اطلاعات در حافظهٔ همین مرورگر ذخیره می‌شوند و رابط برنامه بدون اینترنت کار می‌کند. برای نصب با دکمه، نسخهٔ PWA را روی HTTPS منتشر کن. فایل HTML تنها به‌صورت محلی باز می‌شود و ممکن است نصب خودکار در آن فعال نباشد.
